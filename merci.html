Nous écrire

En nous écrivant, indiquez le courriel utilisé lors de l'achat. Aucun montant ne vous sera facturé deux fois.

Prochaines étapes

  1. Téléchargez le logiciel pour Windows depuis la page Téléchargement et installez-le.
  2. Nouveau client? Ouvrez le courriel d'invitation de MAA Gestion (vérifiez les courriels indésirables) et cliquez sur le lien pour choisir votre mot de passe.
  3. Connectez-vous avec le courriel utilisé lors de l'achat : seul ce courriel peut activer la licence, et il devient le compte administrateur. Entrez votre clé de licence si le logiciel la demande.
  4. Invitez votre équipe depuis « Gérer les accès » dans le logiciel, selon le nombre d'utilisateurs de votre abonnement.
